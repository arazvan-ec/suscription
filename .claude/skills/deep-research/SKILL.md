# Deep Research

## Purpose
Conduct thorough technical or domain research before planning or implementing.
Produces a structured research report.

## When to Apply
- Before bmad-architect when exploring unfamiliar technology
- Before /opsx:propose when the feature involves new patterns
- When someone says "deep-research [topic]"

## Process

### 1. Clarify Research Question
Distinguish between technical, domain, and competitive research.

### 2. Research Sources
- Web search for current best practices
- Codebase search for existing patterns
- project-context.md for constraints

### 3. Produce Structured Report
```markdown
# Research Report: [Topic]

## Question
## Findings
### Option A: [Name]
- How it works
- Pros / Cons
- Fits our stack: yes/no
### Option B: [Name]
## Recommendation
## References
```

### 4. Save Report
Save to `_bmad-output/planning-artifacts/research-[topic-slug].md`
